# API Reference — Jyoti.AI Backend

**Base URL**: `https://your-backend-url.com` (or `http://localhost:8000` for local development)

**Content-Type**: `application/json`

---

## Endpoints

### `POST /chat/`

Stream a conversational AI response grounded in the candidate's profile.

**Request Body**

| Field | Type | Required | Constraints | Description |
|---|---|---|---|---|
| `question` | `string` | ✅ | 1–2000 chars | The user's question |
| `history` | `Message[]` | ❌ | Max 30 items | Previous conversation turns |
| `job_description` | `string \| null` | ❌ | Max 10000 chars | Active JD for context-aware responses |

**`Message` schema**

| Field | Type | Values |
|---|---|---|
| `role` | `string` | `"user"` or `"assistant"` |
| `content` | `string` | Max 5000 chars |

**Example Request**

```json
{
  "question": "What projects has Jyoti built?",
  "history": [
    {
      "role": "user",
      "content": "Tell me about Jyoti"
    },
    {
      "role": "assistant",
      "content": "Jyoti is an AI Engineer..."
    }
  ],
  "job_description": null
}
```

**Response**

- **Content-Type**: `text/plain; charset=utf-8`
- **Transfer**: Streamed (chunked transfer encoding)
- Tokens are delivered incrementally as they are generated by the LLM.

**Error Responses**

| Status | Description |
|---|---|
| `400` | Invalid request (empty question, malformed history) |
| `404` | Candidate profile not found on server |
| `422` | Validation error (Pydantic) |
| `500` | Unexpected server error |

### `POST /chat/job-match`

Analyze a job description against the candidate profile. Returns a structured JSON evaluation report.

**Request Body**

| Field | Type | Required | Constraints | Description |
|---|---|---|---|---|
| `job_description` | `string` | ✅ | 10–10000 chars | Full job description text |

**Example Request**

```json
{
  "job_description": "We are looking for a Python Engineer with experience in FastAPI..."
}
```

**Response**

```json
{
  "score": 72,
  "confidence": "Medium",
  "recommendation_level": "Recommend",
  "reason": "Strong alignment in Python/FastAPI backend ...",
  "strengths": [
    {
      "skill": "Python",
      "evidence": "Primary language used across all projects",
      "requirement_matched": "3+ years Python experience"
    }
  ],
  "missing_skills": [
    {
      "skill": "Docker",
      "requirement_unmet": "Containerization with Docker/Kubernetes"
    }
  ],
  "critical_missing_requirements": [
    "5+ years of production experience"
  ],
  "transferable_skills": [
    {
      "skill": "FastAPI deployment on Render",
      "could_substitute_for": "Cloud deployment experience",
      "reasoning": "Demonstrates cloud deployment fundamentals"
    }
  ],
  "evidence_for_deductions": [
    "No Docker or Kubernetes experience found in profile"
  ],
  "risks": [
    "Early-career candidate — limited production experience"
  ],
  "skill_breakdown": {
    "Backend": 85,
    "Frontend": 70,
    "AI/Data": 80,
    "Infrastructure/Cloud": 30
  },
  "interview_recommendation": "Proceed with technical screen focusing on...",
  "suggested_questions": [
    "Walk us through how you architected the streaming pipeline in AI Portfolio",
    "How would you approach containerizing a FastAPI application?"
  ],
  "learning_roadmap": [
    "Complete Docker fundamentals and containerize an existing project",
    "Deploy a service to a managed Kubernetes platform (GKE, EKS)"
  ],
  "final_verdict": "Strong foundational candidate for a junior-to-mid Python/AI role"
}
```

**Error Responses**

| Status | Description |
|---|---|
| `400` | Invalid request (JD too short or empty) |
| `404` | Candidate profile not found |
| `422` | Validation error |
| `502` | LLM returned invalid JSON |
| `500` | Unexpected server error |
